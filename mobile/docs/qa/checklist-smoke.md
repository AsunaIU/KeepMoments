# Smoke-чек-лист

- [ ] Приложение запускается, не падает на старте
- [ ] Экран входа открывается, пустые поля не проходят валидацию
- [ ] Регистрация нового аккаунта проходит
- [ ] Вход существующим аккаунтом проходит
- [ ] Выбор фото из галереи работает, превью показывается
- [ ] Невалидное фото (большое / чужой формат) помечается с сообщением
- [ ] Черновик создаётся и виден в списке
- [ ] Черновик удаляется
- [ ] Генерация книги доходит до результата или показывает понятную ошибку
- [ ] Экспорт в PDF создаёт открываемый файл
- [ ] При выключенной сети приложение не виснет и показывает ошибку
- [ ] Тёмная тема не ломает вёрстку ключевых экранов

Если что-то из этого красное — сборку не отдаю, завожу баг.
