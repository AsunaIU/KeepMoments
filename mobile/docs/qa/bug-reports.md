## BUG-001

- Заголовок: генерация книги без сети висит на лоадере до таймаута (~3 мин), потом ошибка
- Severity: Major / Priority: Medium
- Окружение: Pixel 6, Android 13, debug
- Предусловия: авторизован, в черновике есть валидные фото
- Шаги:
  1. Включить режим полёта
  2. Открыть черновик → «Продолжить»
- Фактический результат: индикатор крутится ~3 минуты (до `callTimeout` OkHttp), кнопки недоступны, только потом появляется ошибка
- Ожидаемый результат: ошибка сети показывается быстрее, есть возможность отменить/повторить
- Примечания: чаще воспроизводится, когда сеть обрывается уже во время запроса

## BUG-002

- Заголовок: сообщение об ошибке входа не сбрасывается при повторной попытке
- Severity: Minor / Priority: Low
- Окружение: эмулятор Pixel 5, Android 11, debug
- Предусловия: экран входа
- Шаги:
  1. Ввести неверный пароль → «Войти» → появляется ошибка
  2. Исправить пароль на верный → «Войти»
- Фактический результат: на мгновение ещё видно старое сообщение об ошибке перед переходом
- Ожидаемый результат: старая ошибка скрывается сразу при новой отправке
