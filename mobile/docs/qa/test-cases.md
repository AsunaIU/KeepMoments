# Тест-кейсы

Ручные кейсы на основные сценарии. Приоритет: P1 — критично, P2 — важно, P3 — второстепенно.

## Авторизация

Предусловие: приложение установлено, для позитивных кейсов есть интернет.

| ID | P | Проверка | Шаги | Ожидаемый результат |
|----|---|----------|------|---------------------|
| AUTH-01 | P1 | Вход с верными данными | Экран входа → ввести существующие email/пароль → «Войти» | Вход успешен, попадаем на главный, email виден в профиле |
| AUTH-02 | P1 | Регистрация | «Регистрация» → новый email и пароль ≥6 → «Создать аккаунт» | Аккаунт создан, автоматический вход |
| AUTH-03 | P2 | Пустой email | Оставить email пустым → «Войти» | Сообщение «Введите email», запрос не уходит |
| AUTH-04 | P2 | Короткий пароль | Пароль из 3 символов → отправить | Сообщение «Пароль должен быть не короче 6 символов» |
| AUTH-05 | P1 | Неверные данные | Верный email, неверный пароль → «Войти» | Остаёмся на экране, показывается ошибка сервера |
| AUTH-06 | P2 | Продолжение без входа | Гостем собрать альбом → «Продолжить» | Приложение просит войти в аккаунт |

## Импорт и валидация фото

Предусловие: открыт экран добавления фото.

| ID | P | Проверка | Шаги | Ожидаемый результат |
|----|---|----------|------|---------------------|
| PHOTO-01 | P1 | Обычное JPG | Выбрать корректное .jpg | Добавлено, помечено валидным |
| PHOTO-02 | P2 | PNG | Выбрать .png | Добавлено |
| PHOTO-03 | P2 | Чужой формат | Выбрать .gif | Невалидно, «Поддерживаются только JPG и PNG» |
| PHOTO-04 | P1 | Слишком большое | Фото > 10 МБ | Невалидно, «Размер файла больше 10 МБ» |
| PHOTO-05 | P2 | Слишком маленькое | Фото ~300×300 | Невалидно, «Фото слишком маленькое для хорошего качества» |
| PHOTO-06 | P2 | Дубликат | Добавить одно и то же фото дважды | Второй раз не добавляется |
| PHOTO-07 | P2 | Лимит 50 | Попытаться добавить 51+ фото | Берутся первые 50, показывается сообщение про лимит |

Границы по размеру и разрешению (10 МБ ±1 байт, сторона 400/399, площадь 240000/239999) закрыты автотестом `PhotoValidatorTest`; вручную проверяю крайние по «на глаз» большим/маленьким файлам.

## Черновики

Предусловие: есть минимум одно валидное фото.

| ID | P | Проверка | Шаги | Ожидаемый результат |
|----|---|----------|------|---------------------|
| DRAFT-01 | P1 | Создание (гость) | Без входа выбрать фото → создать черновик | Черновик появился в списке |
| DRAFT-02 | P2 | Создание (пользователь) | Войти → создать черновик | Привязан к аккаунту, виден после перезахода |
| DRAFT-03 | P1 | Удаление | Удалить черновик из списка | Пропал из списка, локальные копии фото удалены |
| DRAFT-04 | P3 | Переименование | Задать новое имя черновику | Имя сохранилось после выхода и возврата |
| DRAFT-05 | P2 | Видимость | Создать черновик гостем → войти под аккаунтом | Гостевые видны, чужие пользовательские — нет |
